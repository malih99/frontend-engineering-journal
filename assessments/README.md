# Assessments

Objective checkpoints instead of "I feel better". Repeat the same benchmarks at the start,
around week 12, and at the end. Rules: 20-minute time box per task, no AI, no copy-paste.

Name files `YYYY-MM-<name>.md` (for example `2026-10-baseline.md`). Set `independent: true` only if
you finished the task alone inside the time box; leave `null` for tasks not attempted.
